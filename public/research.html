Laboratorium Evaluasi NoSQL Injection

Topik: "Evaluasi Efektivitas Middleware Sanitasi terhadap Serangan NoSQL Injection pada REST API Berbasis MongoDB"

Live Playground Benchmark Otomatis 4 Varian Proteksi

Arsitektur 4 Varian REST API

Semua varian menggunakan model dan logika bisnis yang 100% identik. Satu-satunya variabel pembeda adalah lapisan proteksi middleware.

V0

Baseline (Tanpa Proteksi)

/api/v0

  • express-mongo-sanitize: Nonaktif
  • Validasi Skema Joi: Nonaktif
  • Sebagai titik acuan (baseline) kerentanan
V1

Sanitasi Saja

/api/v1

  • express-mongo-sanitize: Aktif
  • Validasi Skema Joi: Nonaktif
  • Mengubah key $ dan . menjadi _
V2

Validasi Skema Joi Saja

/api/v2

  • express-mongo-sanitize: Nonaktif
  • Validasi Skema Joi: Aktif
  • Memvalidasi tipe data ketat di gerbang API
V3

Kombinasi Proteksi

/api/v3

  • express-mongo-sanitize: Aktif
  • Validasi Skema Joi: Aktif
  • Pertahanan berlapis ganda (Defense-in-Depth)
